## 3. 用例与预期

### S1 CAS 登录全链

| 用例 | 步骤 | 预期 |
|---|---|---|
| S1-1 登录入口 | 打开 :5279/login | 显示"统一身份认证登录"按钮(口令表单已下线) |
| S1-2 跳转 CAS | 点击按钮 | 302 至 CAS 登录页,service 指向基座接票页 `/cas-ticket` |
| S1-3 CAS 认证 | 输入 admin/admin123 提交 | CAS 校验通过,302 回 `cas-ticket?ticket=ST-xxx` |
| S1-4 接票换 token | 自动 | 前端 POST `/v1/auth/cas/callback`(ticket+service)→ 200 TokenResp;**POST 契约不因 CAS GET 重定向破坏** |
| S1-5 会话建立 | 自动 | localStorage 存 token;`/v1/me` 返回 claims `{sub:"admin", roles:["super_admin"], tenant:"platform", typ:"access"}`;进入工作台 |
| S1-6 失败分支 | 停掉 CAS 后登录 | callback 返回 503 `AUTH_CAS_UNAVAILABLE`,不发 token(fail-closed) |

### S2 基座权限数据链

| 用例 | 步骤 | 预期 |
|---|---|---|
| S2-1 菜单全量 | admin(超管,通配规则 `*:read`)展开菜单 | 目录内全部服务可见 |
| S2-2 菜单裁剪 | zhangsan(readonly,仅 `redis:read`)登录 | 只见 Redis,其余隐藏(fail-closed) |
| S2-3 按钮级 | 六页写按钮 | 权限码含 `authz:manage` → 可见;否则隐藏 |
| S2-4 通配语义 | hasPermission 单测矩阵 | `*:read` 授予任意服务读;**不授予** `authz:manage`;`<服务>:*`/`*:*`/`*` 各按语义 |

### S3 管理界面六页

| 用例 | 步骤 | 预期 |
|---|---|---|
| S3-1 组织树 CRUD | 建根/建子/改名/删除 | 生效且有审计记录;有子组织时删除按钮禁用 |
| S3-2 成员管理 | UserSelect 加人/移除 | 成员列表回显;写引擎元组即时生效 |
| S3-3 角色分配 | assign/revoke(用户/组织) | 写元组;白名单外角色 400 `AUTHZ_ROLE_UNKNOWN` |
| S3-4 规则表 | Upsert/Delete 规则 | 保存后 `/me/permissions` 派生即时反映 |
| S3-5 审计 | 各写操作后查审计页 | 记录操作人/动作/快照/状态;支持分页与 userId 过滤 |
| S3-6 页面报错 | 遍历六页与基座页面 | 无白屏/无未处理异常(用户报告的报错需定位根因并修复) |

### S4 组织授权与继承(新)

| 用例 | 步骤 | 预期 |
|---|---|---|
| S4-1 用户直接授权 | assign readonly → zhangsan | 重新登录后 roles claim 含 readonly |
| S4-2 授予组织 | assign operator → org 研发部 | 该组织**直接成员**重新登录后获得 operator |
| S4-3 继承方向 | lisi 加入 root(父);readonly 授予 root 的子组织 | **父组织成员沿 parent 链向下继承**:lisi 获得该角色 |
| S4-4 不越界 | zhangsan(研发部成员,与 root 无关) | 授予 root 的角色**不**落到 zhangsan |
| S4-5 对称撤销 | revoke 同 targetType | 组织成员失去角色 |
| S4-6 非法目标 | 授予不存在的组织 | 404 `AUTHZ_ORG_NOT_FOUND` |

> 说明:继承方向由模型 `org.member = member from parent` 决定——**上级组织的成员自动成为下级组织成员**,故"角色授予下级组织时,上级组织的成员(经继承)获得该角色"。这与日常直觉的"授予父组织全员生效"方向相反,是 OpenFGA 关系方向的固有语义,测试按真实语义断言(见报告 §4)。

### S5 用户档案收敛(新)

| 用例 | 步骤 | 预期 |
|---|---|---|
| S5-1 目录搜索 | GET /v1/auth/users?keyword=zhang | 返回 zhangsan(裸用户名口径) |
| S5-2 批量反查 | ?ids=admin,zhangsan,lisi | 三条全回,供审计/成员抽屉渲染姓名 |
| S5-3 鉴权 | 普通用户 token 调目录 | 403(super_admin only) |
| S5-4 持久化 | auth 重启(MySQL 模式)后查询 | 已登录过的用户档案仍在(**修复点**:内存实现重启即丢) |

### S6 OpenFGA 能力探针(新)

用独立探针模型 + 底层官方 client,逐项验证平台未用的引擎能力:

| 用例 | 能力 | 预期 |
|---|---|---|
| S6-1 公开访问 | `[user, user:*]` + 写 `user:*` 元组 | 任意用户可读;未授权对象仍拒绝 |
| S6-2 排除 | `viewer = direct but not banned` | 黑名单成员被拒,其余通过 |
| S6-3 条件(ABAC) | 元组带 condition,Check 传 context | 满足→授权;不满足→拒绝 |
| S6-4 上下文元组 | check 时临时附加元组 | 本次 check 生效,**不落库**(再次 check 拒绝) |
